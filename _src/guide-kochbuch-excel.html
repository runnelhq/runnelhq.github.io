Anpassen

  • sheet und range an die eigene Mappe anpassen: range: A3 heißt, die Tabelle beginnt mit der Kopfzeile in A3; emptyRows: stop endet an der ersten leeren Zeile, etwa vor einer Summenzeile.

  • Beim Schreiben bleibt eine Zahl eine Zahl: format nimmt ein Runnel-Muster wie #.##0,00, excelFormat einen eigenen Excel-Code wie #,##0.00 "€". Mit ifExists: sheet ersetzt Runnel nur ein Blatt einer vorhandenen Mappe.

Reading and writing Excel

Reads orders from an Excel workbook and writes them as a CSV file and as a new, formatted workbook. Faulty rows go into a separate file.

Components
excel.input, excel.output, csv.output
Sign-in
none – files only
Status
Checked on 2026-11-27 with Runnel v0.1.0-alpha.13: runnel validate and run completely with the recipe's sample data.

Prerequisites

No accounts or keys needed.

Files

{{snippet:../kochbuch/excel/project.yaml|project.yaml}} {{snippet:../kochbuch/excel/pipelines/orders.pipeline.yaml|pipelines/orders.pipeline.yaml}} {{snippet:../kochbuch/excel/workflows/export.workflow.yaml|workflows/export.workflow.yaml}}

The sample workbook data/orders.xlsx has a title above the table and a sum row below it; order 1004 contains #N/A as amount and goes over the error link into out/excel-rejected.csv. The workflow creates the folder out because the outputs don't create missing folders.

Running

In the recipe folder (PowerShell):

runnel run workflows/export.workflow.yaml

Adapting

  • Adapt sheet and range to your workbook: range: A3 means the table starts with its header in A3; emptyRows: stop ends at the first empty row, e.g. before a sum row.
  • Numbers, dates and booleans already come typed from Excel; fields only picks the columns and checks their types. Columns with another name are taken with from.
  • When writing, a number stays a number: format takes a Runnel pattern such as #.##0,00, excelFormat a custom Excel code such as #,##0.00 "€". With ifExists: sheet Runnel replaces just one sheet of an existing workbook.
