Weather (Open-Meteo)

Reads the current temperature and wind speed for a place. No sign-in – the simplest recipe to try things out.

API
Open-Meteo Forecast API, free for non-commercial use
Sign-in
none
Status
Checked on the Runnel side on 2026-11-23: runnel validate and runs against a test server that mimics the API. Not yet run against the real API – endpoints and fields per the provider's documentation (as of 11/2026).

Prerequisites

No accounts or keys needed.

Adapting

  • Set LAT, LON, PLACE as parameters or defaults.
  • Request more values under current, e.g. relative_humidity_2m; they appear under body.current.
