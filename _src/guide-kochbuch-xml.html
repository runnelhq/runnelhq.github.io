Anpassen

User guide · Cookbook

XML exchange

Reads orders from an ERP system's XML export and writes them as CSV and as XML in the structure a partner expects.

Components
xml.input, xml.output, csv.output
Sign-in
none – files only
Status
Checked on 2026-11-27 with Runnel v0.1.0-alpha.13: runnel validate and run completely with the recipe's sample data.

Prerequisites

No accounts or keys needed.

Files

{{snippet:../kochbuch/xml/project.yaml|project.yaml}} {{snippet:../kochbuch/xml/data/orders.xml|data/orders.xml}} {{snippet:../kochbuch/xml/pipelines/orders.pipeline.yaml|pipelines/orders.pipeline.yaml}} {{snippet:../kochbuch/xml/workflows/export.workflow.yaml|workflows/export.workflow.yaml}}

Order 1004 has “k. A.” as amount and goes over the error link to out/xml-rejected.csv, with the order's line in _error.

Running

In the recipe folder (PowerShell):

runnel run workflows/export.workflow.yaml

Adapting

  • records is the path of the elements that are records (Bestellungen/Bestellung); namespace prefixes are not written.
  • When reading, from takes an attribute (@nr), a nested element (Kunde/Name) or its attribute (Kunde/@id).
  • When writing, as decides where a field goes: as an attribute (@number) or nested (customer/name); root and record name the root and record elements.
