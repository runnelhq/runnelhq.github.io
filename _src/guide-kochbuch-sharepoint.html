SharePoint (Microsoft Graph)

Lädt ZIP-Dateien aus einer SharePoint-Dokumentbibliothek herunter, entpackt sie und liest die enthaltenen CSV-Dateien in eine Datei. Das Rezept zeigt die Anmeldung mit OAuth2 (Client Credentials) und den Download mit saveTo.

API
Microsoft Graph, Inhalt einer Datei herunterladen
Anmeldung
OAuth2 Client Credentials einer in Microsoft Entra registrierten Anwendung
Stand
Runnel-seitig geprüft am 24.11.2026: runnel validate und Ausführung gegen einen Testserver mit Token-Abruf, Weiterleitung und ZIP-Download. Gegen Microsoft Graph noch nicht ausgeführt – nach der Dokumentation von Microsoft (Stand 11/2026).

SHAREPOINT_SITEVariableSite als host:/pfad:, z. B. contoso.sharepoint.com:/sites/Finance:
GRAPH_CLIENT_SECRETSecretGeheimer Clientschlüssel der Anwendung

Secrets kommen hier aus Umgebungsvariablen (secretStore: env in project.yaml). Für den Dienst die Variable beim Dienstkonto setzen.

Runnel holt das Token selbst und hält es bis kurz vor Ablauf im Speicher. Graph beantwortet …:/content mit einer Weiterleitung zum Download; zu einem anderen Host geht das Token dabei nicht mit. saveTo schreibt die Antwort direkt in eine Datei, ihr Pfad steht in output.path. Die Dateien werden nacheinander verarbeitet (forEach ohne parallel), weil alle an dieselbe CSV-Datei anhängen.

Ausführen

Im Ordner des Rezepts (PowerShell):

$env:GRAPH_CLIENT_SECRET = "…"
runnel run -v workflows/orders.workflow.yaml
runnel run -v --param 'PATHS=["Exports/2026/orders-north.zip"]' workflows/orders.workflow.yaml

Anpassen

  • In Microsoft Entra eine Anwendung registrieren und ihr die Anwendungsberechtigung Sites.Selected geben (Zugriff je Site freigeben, empfohlen) oder Files.Read.All; einen geheimen Clientschlüssel anlegen.
  • Die Pfade der Dateien stehen im Parameter PATHS (JSON-Liste), relativ zur Dokumentbibliothek der Site.
  • Für andere Dateiarten den Schritt unpack weglassen und die Pipeline direkt mit results.download.output.path aufrufen.
  • Andere Graph-Endpunkte (Mail, Teams, Benutzer) nutzen dieselbe Connection; Listen mit paginate: { style: url, next: "@odata.nextLink", items: value }.

User guide · Cookbook

SharePoint (Microsoft Graph)

Downloads ZIP files from a SharePoint document library, unpacks them and reads the CSV files inside into one file. The recipe shows OAuth2 sign-in (client credentials) and downloading with saveTo.

API
Microsoft Graph, download a file's content
Sign-in
OAuth2 client credentials of an application registered in Microsoft Entra
Status
Checked on the Runnel side on 2026-11-24: runnel validate and runs against a test server with token request, redirect and ZIP download. Not yet run against Microsoft Graph – per Microsoft's documentation (as of 11/2026).

Prerequisites

NameKindMeaning
GRAPH_TENANTVariableTenant, e.g. contoso.onmicrosoft.com
GRAPH_CLIENT_IDVariableApplication (client) ID of the registered application
SHAREPOINT_SITEVariableSite as host:/path:, e.g. contoso.sharepoint.com:/sites/Finance:
GRAPH_CLIENT_SECRETSecretClient secret of the application

Secrets come from environment variables here (secretStore: env in project.yaml). For the service, set the variable for the service account.

Files

{{snippet:../kochbuch/sharepoint/project.yaml|project.yaml}} {{snippet:../kochbuch/sharepoint/connections/sharepoint.yaml|connections/sharepoint.yaml}} {{snippet:../kochbuch/sharepoint/workflows/orders.workflow.yaml|workflows/orders.workflow.yaml}} {{snippet:../kochbuch/sharepoint/workflows/file.workflow.yaml|workflows/file.workflow.yaml}} {{snippet:../kochbuch/sharepoint/pipelines/orders.pipeline.yaml|pipelines/orders.pipeline.yaml}}

Runnel fetches the token itself and keeps it in memory until shortly before it expires. Graph answers …:/content with a redirect to the download; the token does not go along to another host. saveTo writes the response straight into a file, its path is in output.path. Files are processed one after the other (forEach without parallel) because all of them append to the same CSV file.

Running

In the recipe folder (PowerShell):

$env:GRAPH_CLIENT_SECRET = "…"
runnel run -v workflows/orders.workflow.yaml
runnel run -v --param 'PATHS=["Exports/2026/orders-north.zip"]' workflows/orders.workflow.yaml

Adapting

  • Register an application in Microsoft Entra and give it the application permission Sites.Selected (access granted per site, recommended) or Files.Read.All; create a client secret.
  • The file paths are in the parameter PATHS (JSON list), relative to the site's document library.
  • For other file types, drop the unpack step and call the pipeline directly with results.download.output.path.
  • Other Graph endpoints (mail, Teams, users) use the same connection; lists with paginate: { style: url, next: "@odata.nextLink", items: value }.
