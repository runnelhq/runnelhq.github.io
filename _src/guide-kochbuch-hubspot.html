Ausführen

Im Ordner des Rezepts (PowerShell):

$env:HUBSPOT_TOKEN = "pat-…"
runnel run workflows/contacts.workflow.yaml
runnel run --param EMAIL=ada@example.com --param FIRSTNAME=Ada workflows/create-contact.workflow.yaml

Anpassen

  • Weitere Eigenschaften über query.properties lesen bzw. unter body.properties schreiben.
  • Firmen und Deals funktionieren gleich: crm/v3/objects/companies, crm/v3/objects/deals.
  • Gibt es eine E-Mail schon, antwortet HubSpot mit 409. Mit failOnError: false und einem Link mit Bedingung auf result.output.status lässt sich das abfangen.

User guide · Cookbook

HubSpot

Reads all contacts from the HubSpot CRM and creates new contacts. create-contact is a connector with parameters and the ID as output.

API
HubSpot CRM API v3, Contacts
Sign-in
Private app access token as bearer
Status
Checked on the Runnel side on 2026-11-23: runnel validate and runs against a test server that mimics the API. Not yet run against the real API – endpoints and fields per the provider's documentation (as of 11/2026).

Prerequisites

NameKindMeaning
HUBSPOT_TOKENSecretAccess token of a private app with the scopes crm.objects.contacts.read and .write

Secrets come from environment variables here (secretStore: env in project.yaml). For the service, set the variable for the service account.

Files

{{snippet:../kochbuch/hubspot/project.yaml|project.yaml}} {{snippet:../kochbuch/hubspot/connections/hubspot.yaml|connections/hubspot.yaml}} {{snippet:../kochbuch/hubspot/workflows/contacts.workflow.yaml|workflows/contacts.workflow.yaml}} {{snippet:../kochbuch/hubspot/workflows/create-contact.workflow.yaml|workflows/create-contact.workflow.yaml}}

HubSpot returns the next page's cursor in paging.next.after and expects it as the query parameter after, hence style: cursor. On the last page paging.next is missing.

Running

In the recipe folder (PowerShell):

$env:HUBSPOT_TOKEN = "pat-…"
runnel run workflows/contacts.workflow.yaml
runnel run --param EMAIL=ada@example.com --param FIRSTNAME=Ada workflows/create-contact.workflow.yaml

Adapting

  • Read more properties via query.properties or write them under body.properties.
  • Companies and deals work the same: crm/v3/objects/companies, crm/v3/objects/deals.
  • If an e-mail already exists, HubSpot answers 409. With failOnError: false and a link conditioned on result.output.status this can be handled.
