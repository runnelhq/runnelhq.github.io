Bausteine

Alle Actions (für Workflows), Transforms (für Pipelines) und Connection-Typen: Felder unter with:, Ergebnis bzw. gesetzte Felder, was mit den Datensätzen geschieht, Fehler und Grenzen. Die Seite ist aus runnel-catalog.json des Releases erzeugt (runnel catalog --json); Beschreibungen und Beispiele stammen aus dem Programm und sind daher englisch.

Dieselben Angaben zeigt runnel catalog <typ> in der Konsole und der Editor in der Hilfe zum Baustein („?“ oder F1). Derselbe Name kann als Action und als Transform vorkommen (z. B. core.log) – dann mit unterschiedlichen Feldern. Solche Bausteine tragen das Kennzeichen A+T; es verlinkt auf die jeweils andere Art.

Stand der Referenz: Runnel v0.1.0-alpha.13

core.script JavaScriptA+T · auch als Transform

Runs JavaScript with params; output: the value of return

Felder unter with:
FeldTypBeschreibung
scriptstringstringJavaScript, the body of a function: params holds the values, return gives output; ${…} and {{ … }} in it are plain text
filestringstringA .js file instead of script, relative to the project folder, e.g. scripts/total.js
paramsmapmapValues for the script as params.NAME; may use ${…} and {{ … }}, a value of its own may be ${secret:…}
timeoutdurationdurationLongest time the script may run, e.g. 5m
Standard: 1m
Ergebnis in result.output des Schritts
PfadTypBeschreibung
outputanyanyThe value of return, e.g. a number, text, list or object; null without return
Fehler

Fails on a syntax error, an exception (with the line), a result that cannot be converted, a missing or too large script file, and when timeout, the timeout of the action or a cancelled run interrupts the script.

Grenzen
  • timeout limits the script (default 1m).
  • The result may be at most 16 MiB as JSON and nested at most 100 levels; a script file or module may be at most 4 MiB.
  • The console keeps at most 1,000 lines per call, each cut at 8 KiB.
  • No access to files, network, processes or environment variables; require loads modules from scripts/ of the project only.
Beispiel
- id: script
  type: core.script
  with:
    params:
      orders: "{{ results.load.output.rows }}"
      rate: 0.19
    script: |
      const sum = params.orders.reduce((s, o) => s + Number(o.amount), 0);
      console.log(`${params.orders.length} orders`);
      return { net: sum, gross: sum * (1 + params.rate) };
