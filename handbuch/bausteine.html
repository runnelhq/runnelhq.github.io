Bausteine

Alle Actions (für Workflows) und Transforms (für Pipelines) mit ihren Feldern unter with:. Die Seite ist aus runnel catalog --json erzeugt; Beschreibungen und Beispiele stammen aus dem Programm und sind daher englisch.

Dieselben Angaben zeigt runnel catalog <typ> in der Konsole und der Editor im Eigenschaftsdialog. Derselbe Name kann als Action und als Transform vorkommen (z. B. core.log) – dann mit unterschiedlichen Feldern. Solche Bausteine tragen das Kennzeichen A+T; es verlinkt auf die jeweils andere Art.

Runs a PowerShell script with named parameters; output: exitCode, stdout, stderr and optionally JSON

FeldTypBeschreibung

filestring runnel-scriptA script file instead of script, relative to the project folder, e.g. scripts/cleanup.ps1

http.request HTTP Request

Sends an HTTP request, e.g. to a REST API; output: status, headers and body of the answer

FeldTypBeschreibung
methodstringHTTP method
Standard: "GET" · Werte: GET, POST, PUT, PATCH, DELETE, HEAD
connectionstring runnel-connectionConnection of the API (a file in connections/) with base address and sign-in; empty: url is a full address
urlstringAddress with http:// or https://, e.g. https://api.example.com/orders; with connection relative to its baseUrl, e.g. orders
queryobjectQuery parameters, added to the address with encoding, e.g. status: open
headersobjectHeaders of the request, e.g. Accept; tokens belong into a connection, never into the file
bodyanyBody: a text is sent as text, other values (maps, lists, numbers) as JSON
timeoutstring runnel-durationLongest time for one request and its answer (with paginate: per page), e.g. 30s or 5m; the timeout of the action limits all together
Standard: "60s"
failOnErrorbooleanFail the action if the answer has status 400 or above; false: the status is only in the output
Standard: true
maxSizestringLargest answer to read, e.g. 10MB or 500KB; with paginate per page; with saveTo the largest file (default 1GB)
Standard: "10MB"
saveTostringSaves a successful answer (status 2xx) as a file instead of reading it, e.g. a ZIP or PDF; relative to the project folder or absolute. Written to a temporary file first, so no half file remains; output: path and size instead of body
ifExistsstringWith saveTo, if the file exists: replace it once the download is complete, skip the request, or fail before the request
Standard: "replace" · Werte: replace, skip, fail
retryAfterobjectAsking again when the API answers 429 or 503 with Retry-After (wait in seconds or a date); on by default
retryAfter.maxRetriesintegerMost repeats of one request after 429 or 503 with Retry-After; 0: none
Standard: 3
retryAfter.maxWaitstring runnel-durationLongest wait the API may ask for; a longer one fails the action
Standard: "1m"
paginateobjectReading all pages of a paged API; output: items (all items), count and pages instead of body
paginate.stylestringHow the next page is found: link (header Link rel=next), url (address in the body), cursor (value in the body as query parameter), page (page number) or offset (items read so far)
Pflicht · Werte: link, url, cursor, page, offset
paginate.itemsstringPath to the list of items in the body, e.g. data.items; empty: the body is the list
paginate.nextstringPath in the body to the address of the next page (url) or to the cursor (cursor), e.g. @odata.nextLink or meta.next_cursor
paginate.paramstringQuery parameter for the cursor, page number or offset; empty: cursor, page or offset
paginate.startintegerFirst page number (page) or offset (offset); empty: 1 for page, 0 for offset
paginate.sizeintegerItems per page; a shorter page is the last one; with sizeParam it is also sent
paginate.sizeParamstringQuery parameter for the page size, e.g. per_page or limit
paginate.maxPagesintegerMost pages to read; more fail the action
Standard: 100
paginate.maxItemsintegerMost items to read; more fail the action (use a pipeline for larger amounts)
Standard: 10000
Beispiel
- id: request
  type: http.request
  with:
    connection: shop-api
    url: orders
    query:
      status: open
