Handbuch · Kochbuch

Lexware Office

Liest alle Kontakte aus Lexware Office (vormals lexoffice). Das Rezept zeigt Paginierung mit Seitennummern und den Umgang mit dem Rate-Limit der API.

API
Lexware Office Public API, https://api.lexware.io/v1/ (der frühere Host api.lexoffice.io wird abgelöst)
Anmeldung
API-Schlüssel als bearer
Stand
Runnel-seitig geprüft am 23.11.2026: runnel validate und Ausführung gegen einen Testserver, der die API nachbildet. Gegen die echte API noch nicht ausgeführt – Endpunkte und Felder nach der Dokumentation des Anbieters (Stand 11/2026).

Voraussetzungen

NameArtBedeutung
LEXWARE_API_KEYSecretAPI-Schlüssel aus den Einstellungen von Lexware Office („Öffentliche API“)

Secrets kommen hier aus Umgebungsvariablen (secretStore: env in project.yaml). Für den Dienst die Variable beim Dienstkonto setzen.

Dateien

project.yaml
# Recipe: Lexware Office (formerly lexoffice) with an API key from LEXWARE_API_KEY.
kind: Project
apiVersion: runnel/v1
name: lexware
description: Contacts in Lexware Office
secretStore: env
variables:
  LEXWARE_URL: https://api.lexware.io/v1/
connections/lexware.yaml
kind: Connection
apiVersion: runnel/v1
name: lexware
description: Lexware Office public API with an API key
type: http
with:
  baseUrl: ${LEXWARE_URL}
  auth: bearer
  token: ${secret:LEXWARE_API_KEY}
  headers:
    Accept: application/json
workflows/contacts.workflow.yaml
# Reads all contacts page by page (page from 0, up to 250 per page; the list is in
# "content"). The API allows about 2 requests per second: retryAfter waits when it
# answers 429 with Retry-After, retry repeats the whole request otherwise.
#   runnel run workflows/contacts.workflow.yaml
kind: Workflow
apiVersion: runnel/v1
name: contacts
outputs:
  - name: COUNT
    type: integer
    value: "{{ results.fetch.output.count }}"
actions:
  - id: start
    type: core.start
  - id: fetch
    type: http.request
    retry: { attempts: 3, backoff: 2s, strategy: exponential }
    with:
      connection: lexware
      url: contacts
      paginate:
        style: page
        items: content
        param: page
        start: 0
        size: 250
        sizeParam: size
      timeout: 30s
  - id: report
    type: core.log
    with:
      message: "{{ results.fetch.output.count }} contacts on {{ results.fetch.output.pages }} page(s)"
links:
  - { from: start, to: fetch }
  - { from: fetch, to: report }

Die offizielle Dokumentation (developers.lexware.io) war beim Erstellen nicht erreichbar; Host, Paging und Rate-Limit stammen aus mehreren übereinstimmenden Quellen. Vor dem Einsatz bitte dort prüfen.

Ausführen

Im Ordner des Rezepts (PowerShell):

PowerShell
$env:LEXWARE_API_KEY = "…"
runnel run workflows/contacts.workflow.yaml

Anpassen

  • Die Kontakte stehen je Seite in content; Seiten zählen ab 0, bis zu 250 Einträge je Seite.
  • Die API erlaubt etwa 2 Anfragen pro Sekunde und antwortet darüber mit 429. Sendet sie Retry-After, wartet Runnel; sonst wiederholt retry die Anfrage mit wachsendem Abstand.
  • Weitere Listen mit demselben Muster, z. B. Belege über voucherlist.

Quellen auf GitHub: _src/kochbuch/lexware

User guide · Cookbook

Lexware Office

Reads all contacts from Lexware Office (formerly lexoffice). The recipe shows page-number pagination and handling the API's rate limit.

API
Lexware Office public API, https://api.lexware.io/v1/ (the former host api.lexoffice.io is being retired)
Sign-in
API key as bearer
Status
Checked on the Runnel side on 2026-11-23: runnel validate and runs against a test server that mimics the API. Not yet run against the real API – endpoints and fields per the provider's documentation (as of 11/2026).

Prerequisites

NameKindMeaning
LEXWARE_API_KEYSecretAPI key from the Lexware Office settings (“Public API”)

Secrets come from environment variables here (secretStore: env in project.yaml). For the service, set the variable for the service account.

project.yaml

  - id: fetch

The official documentation (developers.lexware.io) could not be reached when this recipe was written; host, paging and rate limit come from several matching sources. Please check there before use.

Running

In the recipe folder (PowerShell):

PowerShell
$env:LEXWARE_API_KEY = "…"
runnel run workflows/contacts.workflow.yaml

Adapting

  • Contacts are in content per page; pages count from 0, up to 250 entries per page.
  • The API allows about 2 requests per second and answers 429 above that. If it sends Retry-After, Runnel waits; otherwise retry repeats the request with growing delays.
  • Other lists follow the same pattern, e.g. vouchers via voucherlist.
