Handbuch · Kochbuch

Wetter (Open-Meteo)

Liest die aktuelle Temperatur und Windgeschwindigkeit für einen Ort. Ohne Anmeldung – das einfachste Rezept zum Ausprobieren.

API
Open-Meteo Forecast API, für nicht-kommerzielle Nutzung frei
Anmeldung
keine
Stand
Runnel-seitig geprüft am 27.11.2026 mit Runnel v0.1.0-alpha.13: runnel validate und Ausführung gegen einen Testserver, der die API nachbildet. Gegen die echte API noch nicht ausgeführt – Endpunkte und Felder nach der Dokumentation des Anbieters (Stand 11/2026).

Voraussetzungen

Keine Konten oder Schlüssel nötig.

Dateien

project.yaml
# Recipe: current weather from Open-Meteo (no sign-in needed).
kind: Project
apiVersion: runnel/v1
name: open-meteo
description: Current weather from Open-Meteo
variables:
  OPEN_METEO_URL: https://api.open-meteo.com/v1/
connections/open-meteo.yaml
kind: Connection
apiVersion: runnel/v1
name: open-meteo
description: Open-Meteo weather API, free without sign-in for non-commercial use
type: http
with:
  baseUrl: ${OPEN_METEO_URL}
workflows/weather.workflow.yaml
# Reads the current temperature and wind speed for a place.
#   runnel run workflows/weather.workflow.yaml
#   runnel run --param LAT=48.14 --param LON=11.58 --param PLACE=München workflows/weather.workflow.yaml
kind: Workflow
apiVersion: runnel/v1
name: weather
parameters:
  - name: LAT
    description: Latitude
    default: "50.94"
  - name: LON
    description: Longitude
    default: "6.96"
  - name: PLACE
    description: Name of the place for the log
    default: Köln
outputs:
  - name: TEMPERATURE
    type: float
    value: "{{ results.fetch.output.body.current.temperature_2m }}"
actions:
  - id: start
    type: core.start
  - id: fetch
    type: http.request
    with:
      connection: open-meteo
      url: forecast
      query:
        latitude: ${LAT}
        longitude: ${LON}
        current: temperature_2m,wind_speed_10m
        timezone: Europe/Berlin
      timeout: 30s
  - id: report
    type: core.log
    with:
      message: "${PLACE}: {{ results.fetch.output.body.current.temperature_2m }} °C, wind {{ results.fetch.output.body.current.wind_speed_10m }} km/h"
links:
  - { from: start, to: fetch }
  - { from: fetch, to: report }

Ausführen

Im Ordner des Rezepts (PowerShell):

PowerShell
runnel run workflows/weather.workflow.yaml
runnel run --param LAT=48.14 --param LON=11.58 --param PLACE=München workflows/weather.workflow.yaml

Anpassen

  • LAT, LON, PLACE als Parameter oder Standardwerte setzen.
  • Weitere Werte unter current abfragen, z. B. relative_humidity_2m; sie stehen dann unter body.current.
  • Für kommerzielle Nutzung die Bedingungen von Open-Meteo beachten.

Quellen auf GitHub: _src/kochbuch/open-meteo

User guide · Cookbook

Weather (Open-Meteo)

Reads the current temperature and wind speed for a place. No sign-in – the simplest recipe to try things out.

API
Open-Meteo Forecast API, free for non-commercial use
Sign-in
none
Status
Checked on the Runnel side on 2026-11-27 with Runnel v0.1.0-alpha.13: runnel validate and runs against a test server that mimics the API. Not yet run against the real API – endpoints and fields per the provider's documentation (as of 11/2026).
